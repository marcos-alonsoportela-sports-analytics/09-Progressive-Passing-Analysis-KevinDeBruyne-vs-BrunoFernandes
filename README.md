# 09- Progressive Passing Analysis — Kevin De Bruyne vs Bruno Fernandes
Spatial and comparative analysis of both players' progressive passes to explore their ability to advance the ball and generate play.

## 📌 Overview

This project analyses the progressive passing profiles of Kevin De Bruyne and Bruno Fernandes in the English Premier League, using Python and football event data to explore their contribution to ball progression.

The analysis first examines Kevin De Bruyne's progressive passes and then compares his passing profile with Bruno Fernandes to identify similarities and differences in their approach to advancing play.

## 🎯 Objectives

- Identify and visualise progressive passes.
- Analyse the spatial distribution of progressive passing actions.
- Compare the passing profiles of two elite midfielders.
- Explore how each player contributes to ball progression.
- Apply event-data analysis and football-specific visualisation techniques.

## 🔬 Methodology

The analysis follows these steps:

1. Load and prepare the football event data.
2. Filter the relevant passing actions for each player.
3. Identify progressive passes according to the criteria implemented in the analysis.
4. Visualise the location and direction of progressive passes.
5. Compare Kevin De Bruyne's and Bruno Fernandes's passing profiles.
